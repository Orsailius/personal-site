Lang V0.1
Match
Check if an expression is equal to multiple values without repeating yourself. You can also specify an expression to evaluate to check if its true. Use the 'it' variable to refer to the result of the expression.
Swizzles
Swizzles let you easily manipulate properties in different ways. You can get and set any combination of variables in single statements by combining their names. Variable names in a swizzle must be 1 character long. Swizzle getters return a tuple, and setters expect one.
Conditionals
We support normal c-style if/else if/else statements as well as the ternary operator. In addition we support the binary if operator (omit the : to not have an else statement)
Data Types
Ints, strings, doubles, etc. More notable are the literals for arrays, maps and ranges
Coroutines
Adding a $ at the end of a method name signifies it is a coroutine. This transforms return statements into yield statements that can be continued upon
Catalogs
Catalogs are enhanced enums that have the properties of normal classes. Catalogs can also be iterated over, contain their name and id, and can be randomly selected.
Extensions
Extensions allow you to add methods to class in a different location
Errors
Errors have first order support and you can declare them by mention. The code '@:MyError create or references a specific error symbol you can use. No more returning null or -1 or other weird constants on failure. Errors are also optional; you don't have to write obnoxious try catch statements around other code you maybe didn't even write that breaks your codes flow. Use @ in front of a variable to refer to errors it may have, @myVar is true if there was an error, and false otherwise. You can test equality against @myVar with an error symbol to see if it is a specific error.
Methods
Normal methods, arrow methods and lambdas
Anonymous Objects
You can create anonymous objects using ${} syntax. Errors can be given Anonymous objects by using : between the error and the object
